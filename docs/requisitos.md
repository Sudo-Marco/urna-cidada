# Requisitos — Urna Cidadã

## 1. Objetivo

Desenvolver um simulador educativo de urna eletrônica para demonstrar o processo de votação e promover a conscientização sobre cidadania digital e desinformação eleitoral.

## 2. Tecnologias previstas

- **Java:** linguagem principal.
- **Java Swing:** interface gráfica.
- **Firebase Cloud Firestore:** persistência de dados na nuvem.
- **Git e GitHub:** controle de versão e colaboração.

## 3. Funcionalidades previstas

- Apresentar candidatos fictícios.
- Permitir votação sequencial para dois cargos: um proporcional e um majoritário.
- Validar as escolhas realizadas durante a votação.
- Registrar os votos conforme as regras definidas para o simulador.
- Apresentar mensagens e orientações ao eleitor durante o processo.
- Persistir os dados necessários no Firestore, após definição do modelo de dados.
- Disponibilizar material educativo sobre desinformação eleitoral e verificação de conteúdos.

## 4. Pendências de definição

- Definir os cargos fictícios e os candidatos.
- Especificar o fluxo completo da votação.
- Definir como votos brancos e nulos serão tratados.
- Definir quais dados serão armazenados na nuvem.
- Elaborar o diagrama de casos de uso e o diagrama de classes.
- Definir os critérios de teste e validação.

## 5. Observação

Este documento é uma versão inicial. As regras detalhadas deverão ser discutidas e aprovadas pelo grupo antes da implementação.
